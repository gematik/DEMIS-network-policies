This Helm Chart creates different Istio Objects that shapes the traffic and defines the rules for establishing a network connection with the cluster services.

The Rules are grouped by target, such as:

- `mesh` contains all the Cluster-Wide Service Mesh configurations
- `idm` contains specific rules for accessing the Identity Management services
- `demis` contains specific rules for DEMIS services
